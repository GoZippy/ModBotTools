# Security policy — ModBotTools

## Reporting a vulnerability

**Please do not open a public issue, discussion or pull request for a security
problem.**

Report it privately through GitHub: go to this repository's **Security** tab and
choose **Report a vulnerability**
(https://github.com/GoZippy/ModBotTools/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. If you
used an AI tool to find or describe the issue, say so, and confirm you
reproduced it yourself — we do not accept unverified generated reports.

## What to expect

| Step | Target |
|---|---|
| Acknowledgement | 3 business days |
| Initial assessment | 10 business days |
| Fix or mitigation for a confirmed high/critical issue | 30 days |

We will keep you updated, credit you in the advisory unless you ask us not to,
and coordinate the disclosure date with you.

## Supported versions

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | Best effort — upgrade first |

## Scope

In scope: the code in this repository and the release artifacts we publish.
Out of scope: third-party dependencies (report those upstream — tell us too if
they affect us), and findings that need physical access or an already
compromised machine.
